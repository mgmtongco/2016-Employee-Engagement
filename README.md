# MBI807 - Employee Data Integration

## Project Overview

This repository contains two separate employee engagement datasets used for the MBI807 data management assessment.

The datasets are intentionally maintained as separate files to demonstrate data integration, data quality management, and data preparation for analysis.

## Datasets

### Dataset 1 - Employee Engagement

**File:** `2016 Employee Engagement.xlsx`

This dataset contains employee engagement-related information collected in 2016.

### Dataset 2 - Employee Engagement Comments

**File:** `2016 Employee Engagement_Comments.xlsx`

This dataset contains employee comments and qualitative feedback relating to employee engagement.

## Data Integration

The two datasets will be examined and connected using an appropriate common identifier or matching field.

The integration process will demonstrate:

- Data integration
- Data quality assessment
- Data cleaning
- Data transformation
- Identification of missing or inconsistent data
- Preparation of an integrated dataset for analysis

## Purpose

The purpose of this project is to demonstrate how separate datasets can be assessed, cleaned, integrated, and prepared for meaningful HR data analysis.
